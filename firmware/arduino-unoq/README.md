# Arduino UNO Q Firmware

Physical intervention layer for Seventh Sense: pixels (ambient light
feedback), buttons (intervention feedback), knob (demo tuning), distance
(proximity/presence), thermo (environmental signal), and an optional buzzer
(gentle cue).

**Status:** Not started.

See [`../../docs/device-integration.md`](../../docs/device-integration.md)
and [`../../shared/protocol/serial-commands.md`](../../shared/protocol/serial-commands.md).
