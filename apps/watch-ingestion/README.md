# Watch Ingestion

Body/activity context ingestion from the WRD6100 SKU1 DVT1.1 watch —
activity level, stillness duration, motion variability, HR trend, and skin
temperature trend where accessible. No diagnosis, no medical claims.

**Status:** Not started.
